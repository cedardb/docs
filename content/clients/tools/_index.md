GUI clients, CLI tools, and observability integrations that connect to
CedarDB over the PostgreSQL wire protocol. Unlike the language pages, these
are not tied to a specific programming language.

* [DataGrip]({{< relref "/clients/tools/datagrip" >}}) — JetBrains database IDE
* [DBeaver]({{< relref "/clients/tools/dbeaver" >}}) — cross-platform SQL GUI
* [Grafana]({{< relref "/clients/tools/grafana" >}}) — observability dashboards backed by CedarDB
* [psql]({{< relref "/clients/tools/psql" >}}) — the standard PostgreSQL command-line client
