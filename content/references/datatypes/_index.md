CedarDB strives to support all useful data types, some of them specified by the SQL standard.
We additionally support additional ones popularized by PostgreSQL (e.g., `array`, `jsonb`, `uuid`, etc.).

The complete list of supported data types in CedarDB is as follows:

* [`array`]({{< relref "/references/datatypes/array" >}})
* [`bigint`]({{< relref "/references/datatypes/integer" >}}) (`int8`)
* [`bignumeric`]({{< relref "/references/datatypes/numeric" >}})
* [`bit`]({{< relref "/references/datatypes/bit" >}})
* [`bit varying`]({{< relref "/references/datatypes/bit" >}})
* [`blob`]({{< relref "/references/datatypes/blob" >}}) (`bytea`)
* [`boolean`]({{< relref "/references/datatypes/boolean" >}})
* [`char`]({{< relref "/references/datatypes/text" >}})
* [`character`]({{< relref "/references/datatypes/text" >}})
* [`character varying`]({{< relref "/references/datatypes/text" >}})
* [`date`]({{< relref "/references/datatypes/date" >}})
* [`decimal`]({{< relref "/references/datatypes/numeric" >}})
* [`double precision`]({{< relref "/references/datatypes/float" >}})
* [`enum`]({{< relref "/references/datatypes/enums" >}})
* [`float`]({{< relref "/references/datatypes/float" >}})
* [`integer`]({{< relref "/references/datatypes/integer" >}}) (`int4`)
* [`interval`]({{< relref "/references/datatypes/interval" >}})
* [`json`]({{< relref "/references/datatypes/json" >}})
* [`jsonb`]({{< relref "/references/datatypes/json" >}})
* [`numeric`]({{< relref "/references/datatypes/numeric" >}})
* [`real`]({{< relref "/references/datatypes/float" >}})
* [`smallint`]({{< relref "/references/datatypes/integer" >}}) (`int2`)
* [`tinyint`]({{< relref "/references/datatypes/integer" >}}) (`int1`)
* [`text`]({{< relref "/references/datatypes/text" >}})
* [`time`]({{< relref "/references/datatypes/time" >}})
* [`timestamp`]({{< relref "/references/datatypes/timestamp" >}}) (with or without time zone)
* [`uint1`]({{< relref "/references/datatypes/integer" >}})
* [`uint2`]({{< relref "/references/datatypes/integer" >}})
* [`uint4`]({{< relref "/references/datatypes/integer" >}})
* [`uint8`]({{< relref "/references/datatypes/integer" >}})
* [`uuid`]({{< relref "/references/datatypes/uuid" >}})
* [`varchar`]({{< relref "/references/datatypes/text" >}})
* [`vector`]({{< relref "/references/datatypes/vector" >}})
