CedarDB supports the standard set of PostgreSQL database objects.
Each page covers all operations on that object type: creating, altering, and dropping.

* [Databases]({{< relref "/references/objects/databases" >}}) — `CREATE`, `ALTER`, `DROP DATABASE`
* [Functions]({{< relref "/references/objects/functions" >}}) — `CREATE`, `ALTER`, `DROP FUNCTION`/`PROCEDURE`, `DO`, `CALL`
* [Indexes]({{< relref "/references/objects/indexes" >}}) — `CREATE`, `DROP INDEX`, index types, partial and expression indexes
* [Policies]({{< relref "/references/objects/policies" >}}) — `CREATE`, `ALTER`, `DROP POLICY`, row level security
* [Roles]({{< relref "/references/objects/roles" >}}) — `CREATE`, `ALTER`, `DROP ROLE`, `GRANT`, `REVOKE`
* [Schemas]({{< relref "/references/objects/schemas" >}}) — `CREATE`, `ALTER`, `DROP SCHEMA`, `search_path`
* [Tables]({{< relref "/references/objects/tables" >}}) — `CREATE`, `ALTER`, `DROP TABLE`, constraints, partitioning
* [Views]({{< relref "/references/objects/views" >}}) — `CREATE`, `DROP VIEW`, materialized views, `REFRESH`
