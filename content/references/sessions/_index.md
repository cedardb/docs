Session management statements reset or modify the current database session.

- [Alter System]({{< relref "/references/sessions/altersystem" >}}) — persist server-wide configuration changes to the configuration file
- [Discard]({{< relref "/references/sessions/discard" >}}) — reset session state, including prepared statements and temporary tables
- [Set / Show]({{< relref "/references/sessions/settings" >}}) — inspect and change database and session settings
