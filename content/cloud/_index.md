[CedarDB Cloud](https://app.cedardb.cloud) is the fully managed version of CedarDB.
You don't have to install, patch, or size anything yourself: create a project, connect with any PostgreSQL-compatible client, and start querying.

* [Get Started](./get_started) — sign up, create a project, and connect to it
* [Manage Projects](./manage_projects) — start, stop, reset the password, and delete a project
* [Monitoring](./monitoring) — follow CPU, storage, connections, and sessions
* [Backups](./backups) — back up a project and restore it
* [AI Agents (MCP)](./ai_agents) — query your projects from Claude, Claude Code, and ChatGPT
